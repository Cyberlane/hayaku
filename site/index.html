The safety contract

Uncertainty broadens a run.

Native dependency metadata cannot capture every file read, service, subprocess, or shared state. Hayaku makes those limits explicit.

Full suites remain the CI gate. Production test omission is disabled in this release. Shadow comparisons are finite evidence, and do not establish complete runtime influence.

In your repository
# Generate and review hayaku.json
hayaku init
hayaku doctor

# Both commits must already exist locally
hayaku plan --base BASE --candidate HEAD \
  --output .git/hayaku-plan.json
hayaku explain --plan .git/hayaku-plan.json

Replace BASE with your comparison commit. Native discovery can execute project code; use trusted repositories.
