The safety contract

Uncertainty broadens a run.

Native dependency metadata cannot capture every file read, service, subprocess, or shared state. Hayaku makes those limits explicit.

Native gates remain full. A separate WASI contract enforces copied inputs and denied host capabilities before allowing pass reuse. It does not certify an equivalent native, browser, or service suite.
