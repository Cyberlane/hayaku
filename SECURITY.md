# Security

Hayaku executes configured commands and native discovery in trusted repositories.
It is not a sandbox. Do not inspect untrusted code. Required full suites remain
the CI gate; affected-test proposals are experimental.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/Cyberlane/hayaku/security/advisories/new).
Provide the affected version and a disposable minimal reproduction. Do not put
credentials, raw environment values or private source in public issues.

The latest release is the maintained line. No security response SLA is promised.
