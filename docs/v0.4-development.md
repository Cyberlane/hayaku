# v0.4 development and acceptance map

The requested release combines wider runner integration with five improvements:
qualified whole-suite reuse, a small native project pilot, immutable monorepo
inputs, adversarial qualification, and measured net cost. Strict fallback remains
mandatory wherever the execution context is unqualified.

The first enforceable reuse context is a separate deterministic WASI suite. It
does not establish equivalence with a native Go, Vitest, browser or service suite.
Native runner discovery, terminal results and shadow comparison qualify
independently from execution isolation and production omission.

| Workstream | Required acceptance |
| --- | --- |
| WASI execution and reuse | Immutable capability-limited inputs; fixed virtual host semantics; authenticated passing receipts; unchanged suite reuses, changed inputs execute; failures and boundary violations never reuse |
| First pilot | Hayaku pure test module executes under the new contract; matching second run actually reuses; module/input changes invalidate reuse |
| Monorepo input capture | Explicit generated inputs and linked dependency targets bind bytes, metadata and paths; escapes, collisions, mutation and cancellation reject |
| Native runner expansion | Node, unittest/pytest, Jest and Playwright inventory/results; wider runner catalog and strict JUnit/TRX ingestion; installed native fixtures separated from protocol tests |
| Framework contexts | Reviewed Vitest/Vite version matrix; generated/linked inputs remain separately identified; browser/services never inherit unit-suite assurance |
| Adversarial validation | Unseen reads, missing paths, directory changes, symlink/native/process/network effects, entropy/time, corrupt results and incomplete/cancelled executions cannot mint reusable passes |
| Performance | Phase and suite execution/cache evidence; context-matched comparisons; existing upstream cache hits are not Hayaku savings; negative savings remain visible |
| Distribution | Tests, races, vet, source review, native CI, source/tag/archives/license verification, downloaded-artifact smoke and published capability limits |

Further languages have named full-scope integration and structured report
ingestion where their runner can emit a supported format. Such integration is not
native discovery or qualification. No new catalog entry grants skip authority.
