# v0.5.1

This is the first published Neiro-ready Apple integration release. The v0.5.0 verification gate stopped publication when its Xcode 26.3 fixture exposed two compatibility gaps; that tag remains unchanged.

The release includes the [v0.5.0 capabilities](v0.5.0.md), with corrected installed Xcode 26.3/27.0 result exports and bounded executable hashing that accommodates the installed Swift compiler. Independent enumeration, exact terminal case reconciliation, required full suites and fail-closed source/runtime validation remain enforced. The Apple CI job independently exercises native adapters and Swift shadow challenges on Xcode 26.3.

See [Apple integration](../apple.md) and [release checks](../release-checks.md). Swift Testing, native omission, custom Cloudflare native filtering, and automatic runner/dependency installation remain outside this integration.
