# v0.4.0

Hayaku adds actual whole-suite result reuse for a separate deterministic WASI
contract, richer native evidence integrations and measured-cost tools. Native
affected-test proposals still retain original full suites. This release does not
claim native Go/Vitest equivalence, complete runtime influence for all languages
or affected-only native CI execution.

## Improvements

- Deterministic WASI preview1 execution with validated capabilities, copied
  read-only files, explicit arguments/environment, logical clocks, seeded entropy,
  bounded resources and unsuccessful unsupported effects.
- Private authenticated passing receipts, exact context invalidation and forced
  audits that remove previous receipts before running. Invalid/unavailable caches
  execute again; Windows receipt reuse is disabled pending ACL qualification.
- Explicit generated/linked multi-root input capture, stable manifests, verified
  materialization and a capsule bridge binding original link/mode/provenance
  identity while normalizing guest aliases. Candidate data never substitutes for
  independently produced BASE inputs.
- Additional native Node test, unittest, pytest, Jest and Playwright collection/
  result bridges; pinned cargo-nextest metadata rounded to whole packages. A
  broader language/build-system catalog preserves original full commands and
  strict JUnit/TRX/Swift/libtest imports validate independent case inventories.
- Matching-context net-cost comparison with phase and executed/reused/upstream-
  cached evidence, plus a self-pilot including independent fresh compiler caches,
  source capture, build, execution/reuse, validation and cleanup.

Vitest compatibility now includes exactly 3.2.7/Vite 6.4.3,
4.1.11/Vite 7.3.1 and 4.1.11/Vite 8.1.5. Each has pinned native fixtures;
custom Cloudflare/workerd, VM, browser and typecheck contexts remain unsupported.
Diagnostic dynamic filesystem observations remain additive evidence.

## Checks and boundaries

Tests challenge input/link/mode drift, escapes/cycles/collisions, malformed native
metadata, missing/conflicting terminal outcomes, denied capabilities, tampered
receipts, forced-audit failure, limits and cancellation. The CI matrix requires
full Go test/race/vet, installed native fixture pairs and capsule/pilot checks.
Finite passing fixtures do not qualify arbitrary native runtime or external-state
behavior. Nextest automatic native shadow/case-reconciliation remains future work;
other catalog entries may be full-scope command/report integrations only.

See [verification](../verification.md) for source/test evidence,
[pilot results](../pilot-results.md) for measured samples and
[release checks](../release-checks.md) for actual downloaded-artifact and remote
acceptance. A published archive does not activate a consumer workflow.
