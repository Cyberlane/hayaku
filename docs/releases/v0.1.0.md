# Hayaku v0.1.0

The first public release provides a conservative foundation for planning affected
tests and evaluating proposals against full runs.

## Included

- `init`, `doctor`, `plan`, `explain`, `run`, `shadow` and `version`.
- Exact committed input pairs, old/new influence graphs, strict configuration,
  uncertainty and structured command reports.
- Go graph discovery, full-run reconciliation and experimental Go shadow.
- Cargo, pytest and Vitest discovery foundations; original full-suite fallbacks
  for Bazel, JVM, .NET and Apple tooling.
- Six binaries: macOS, Linux and Windows on amd64/arm64, with `SHA256SUMS`,
  `manifest.json`, safety documentation and license notices.
- [Website](https://cyberlane.github.io/hayaku/) and
  [installation](https://github.com/Cyberlane/hayaku#install).

## Safety and maturity

**Required execution always retains original full suites. Production affected-test
skipping is disabled.** Proposals are experimental. Passing shadow comparisons,
native imports and mutation scores do not prove complete runtime influence.

Go shadow isolates source copies, not external services or shared state.
Non-Go result reconciliation and ordinary installed/generated input qualification
remain pending. Pytest native acceptance and several native adapters are pending.
Explicit local Git objects are required; symlinks, submodules and staged/worktree
modes are unsupported.

Historical local measurements are synthetic, not representative CI savings.
Full-gated shadow adds cost.

Release checks run on Linux amd64 and macOS arm64. The archive builder validates
embedded source, target platform and CGO state for all six cross-builds.
Other targets, including Windows, have cross-compilation evidence only. macOS
binaries are not Apple-signed/notarized. Checksums establish integrity, not
publisher identity. Review the
[safety contract](https://github.com/Cyberlane/hayaku/blob/v0.1.0/docs/safety.md)
and [distribution](https://github.com/Cyberlane/hayaku/blob/v0.1.0/docs/distribution.md).
