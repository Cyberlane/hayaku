# Hayaku v0.2.1

Recommended patch release for native Vitest support, superseding v0.2.0.
**Full suites remain required; production test omission is disabled.**

This patch preserves the configured Vite root and requires reviewed effective
`CI=true` instead of silently replacing configuration context. Native regressions
verify nested roots and rejection of contradictory CI settings. Generated setup
now declares `context.env.CI` for review.

Vitest 4.1.11 supports configured JS/TS dependency proposals, verified Node/runtime
copies, full results and independent shadow comparisons. Release CI qualifies
Node 22.18.0 with Vite 7.3.1 on Linux amd64 and macOS arm64. Other frameworks retain
full-suite fallback commands; other versions/platforms need separate acceptance.

Install a platform archive and verify `SHA256SUMS`, or:

```sh
go install github.com/Cyberlane/hayaku/cmd/hayaku@v0.2.1
```

See [Vitest setup](https://github.com/Cyberlane/hayaku/blob/v0.2.1/docs/vitest.md)
for configuration and limits. No npm publication is needed. Browser, typecheck,
coverage, snapshot updates, partial scopes and escaping dependency links remain
unsupported. Runtime graphs do not prove arbitrary runtime influence; copies do
not isolate external services. No production CI savings or consumer acceptance
are claimed. Windows execution is unqualified; macOS binaries are unsigned and
not notarized. Checksums establish integrity rather than publisher identity.
