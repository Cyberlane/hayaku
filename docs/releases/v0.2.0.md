# Hayaku v0.2.0

Native Vitest support adds configured JS/TS dependency proposals, verified Node
runtime copies, native full results and shadow validation. **Full suites remain
required; production test omission is disabled.**

## Added

- Vitest 4.1.11 native API bridge and configured Vite import influence, including
  TypeScript aliases and project-aware whole-file proposals.
- Explicit Node/dependency identities, bounded verified copies and before/after
  mutation checks. Declared ignored installations work without excluding other
  source inputs.
- Full native execution and Go/Vitest shadow comparisons; stable duplicate-name
  identities, failed/skipped outcomes and incomplete/missing-result rejection.
- Unhandled native errors invalidate comparison. A hidden filesystem dependency
  fixture proves that shadow detects a failure omitted by an import-only proposal.
- Root Vitest manifest detection, reviewed setup documentation, pinned development
  fixtures and mandatory native Linux/macOS CI checks.

## Install

Use the six macOS/Linux/Windows amd64/arm64 archives and verify `SHA256SUMS`, or:

```sh
go install github.com/Cyberlane/hayaku/cmd/hayaku@v0.2.0
```

The standalone CLI needs no npm package. Projects supply their own existing
runner installation. See [Vitest setup](https://github.com/Cyberlane/hayaku/blob/v0.2.0/docs/vitest.md)
for runtime configuration, commands and unsupported modes.

## Limits

Native fixtures bind Node 22.18.0, Vitest 4.1.11 and Vite 7.3.1 on Linux amd64 and
macOS arm64. Other versions/platforms and consumer projects need their own
acceptance. Browser/typecheck/coverage/snapshot-update/partial scopes and escaping
workspace/pnpm dependency links are unsupported. JavaScript test frameworks beyond Vitest
retain full-suite fallback commands.

The graph cannot establish arbitrary runtime influence. Copies are not hermetic
execution or service isolation; no representative CI savings are claimed. Windows
execution is unqualified, macOS binaries are unsigned/not notarized, and checksums
prove integrity rather than publisher identity. Release publication never enrolls
consumers or authorizes omission.
