# Hayaku v0.6.2

Go and TypeScript/Vitest native workspaces for the documented restricted
profiles. This patch checks a supplied Vitest inventory before controller
admission, so forged case identities are rejected consistently on every
architecture. Unsupported controllers still cannot parse source or mint
authority. Valid inventories pass through the same reviewed source, controller,
tool and runtime checks; this does not qualify additional native contexts.

Installed Cargo fixtures now require explicit `HAYAKU_CARGO_REQUIRED=1` in
development acceptance. Ordinary full repository tests no longer run Rust
acceptance just because Cargo is on PATH. The separate installed-runner CI lane
opts in, requires Cargo and retains these checks; it is deferred from this
Go/TypeScript release. Full repository tests, race checks and vet, all four
Vitest compatibility pairs and WASI pilots still gate publication on Linux
and macOS. The core job has a 60-minute budget for its sequential normal,
race and vet steps, matching the measured local duration; test and runtime
resource bounds remain unchanged.

The failed signed v0.6.0 and v0.6.1 tags remain unchanged; neither published a
release. Hosted checks exposed six unformatted Go fixtures, an ARM64-only
assumption in the issuer rejection test, and unqualified Apple/Rust runtime
byte-bound failures. Fixture formatting preserves their normalized programs.
The Apple and Rust failures remain visible in the broader CI lanes; resource
limits were not raised.

Go groups are explicit test packages with reviewed pure helpers, external test
packages and literal read-only string embeds. Vitest groups are test files in
the locked pure source graph. Authenticated passing receipts, complete native
outcomes, drift checks and audits protect reuse. Unknown syntax, effects, hooks,
tools or invocation settings run the complete original scope on every invocation.
Historical test coverage does not authorize reuse.

The qualified Go profile requires Hayaku and its compiler to use Go 1.27.1 on
macOS ARM64 or Linux ARM64. Vitest uses the fixed Linux ARM64 runtime from either
controller: Node 22.18.0, TypeScript 6.0.2, Vitest 4.1.11, Vite 8.2.2 and
Rolldown 1.2.12. Separately installed Docker, immutable image and pinned SDK bytes
are required. Hayaku installs nothing and performs no automatic network fetch.

Four macOS/Linux archives are provided; AMD64 archives do not qualify affected
native execution. Windows, additional languages and external consumer acceptance
remain deferred. Tiny fixtures run faster in full; no representative performance
improvement is claimed.
