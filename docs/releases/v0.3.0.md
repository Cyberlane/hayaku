# Hayaku v0.3.0

Adds native Vitest **runtime observations and strict fallback regressions**.
This is a diagnostic improvement, not a release of safe affected-only execution.
A qualified isolation backend is still pending; required commands remain full.

- Observe dynamic reads, missing-file checks, metadata and directory listings.
- Capture before configuration and user setup; bind source/configuration/context
  and tools; validate bounded reports without storing raw values or source contents.
- Combine observations with static proposals by adding influence only. Missing,
  incomplete or unsupported evidence broadens scope, never silently omits tests.
- Test native dynamic dependencies, malformed/missing streams, symlink escapes,
  descriptor/worker/native/network/subprocess/time/random gaps and strict fallback.

Existing Node 22.18.0 / Vitest 4.1.11 / Vite 7.3.1 fixtures qualify diagnostic
behavior on Linux amd64 and macOS arm64. Other contexts need separate acceptance.
Observational hooks are not a security or complete-input boundary. No CI savings,
consumer qualification or production omission is claimed.

```sh
go install github.com/Cyberlane/hayaku/cmd/hayaku@v0.3.0
```

Six platform archives include licenses, checksums, provenance and updated docs.
See [runtime observations](https://github.com/Cyberlane/hayaku/blob/v0.3.0/docs/runtime-observations.md)
and [Vitest setup](https://github.com/Cyberlane/hayaku/blob/v0.3.0/docs/vitest.md).
Windows native execution remains unqualified; macOS binaries are unsigned and
not notarized. This release does not install runners or enroll consumer pipelines.
