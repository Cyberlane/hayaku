# v0.5.0

Hayaku can now support Neiro's native XCTest and custom Node test environments while preserving every required full test gate.

- SwiftPM XCTest on installed Darwin Swift 6.0–6.4: target dependency and resource ownership, conservative target proposals, independent case inventories, serial passed/failed/skipped outcomes, and shadow comparisons. Explicitly provisioned source-control dependencies are hashed and copied into private build state.
- Xcode XCTest: independent full test enumeration and xcresulttool schema 0.4.0 reconciliation against exact case identities and summary counters. App/UI commands retain their full scheme, plan and destination. Single plan, device and configuration only.
- Generic Node commands: optional verified installed interpreter and dependency tree. Custom Cloudflare Vitest pools remain full generic commands and do not inherit native Vitest filtering or omission authority.
- Installed Apple release CI fixtures and adversarial tests for missing, unexpected, duplicate, repeated and conflicting outcomes, assertion failures, skips, dependency drift and runtime misses.

Native full suites remain required. Swift Testing, parallel SwiftPM execution, plugins/macros/binary targets, Xcode selection/repetition, and automatic dependency/toolchain installation are outside this integration. Existing mixed-framework and consumer CI gates must be retained. Native target metadata does not prove complete runtime influence. WASI receipt reuse remains a separate contract.

See [Apple integration](../apple.md), [implementation status](../implementation-status.md) and [release checks](../release-checks.md). Local fixtures, downloaded release acceptance and Neiro CI acceptance are separate evidence.
